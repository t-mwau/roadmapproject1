# One Page CV

A The page presents a professional summary, contact details, education, technical and non-technical skills, work experience, certifications, and featured projects in one  document.



## Overview

This project is a static, dependency-free HTML CV which is structured for readability and straightforward maintenance, with each section of the CV represented as its own `<section>` block.

## Project instructions

https://roadmap.sh/projects/single-page-cv

## Structure

```
index.html
```

The document is organized into the following sections:

- **Header / Summary** — Name, title, and a short professional summary
- **Contact Information** — Location, email, phone, and links to portfolio, GitHub, and LinkedIn
- **Education** — Academic background
- **Technical Skills** — Core frontend and development competencies
- **Non-Technical Skills** — Soft skills and professional attributes
- **Experience** — Work history, including role, organization, location, dates, and key achievements
- **Training & Certifications** — Completed courses with links to verifiable certificates
- **Featured Projects** — Selected project work with links to live demos

## Technologies Used

- HTML5

No external stylesheets, scripts, or frameworks are currently included. The page relies on default browser styling.

## Getting Started

To view the CV locally:

1. Clone or download the repository.
2. Open `index.html` directly in a web browser, or serve it with a local development server, for example:
   ```
   npx serve .
   ```

No build steps or dependencies are required.
